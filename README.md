# Git зертханасы

Бұл шағын сайт Git және GitHub ұғымдарын таныстырады.

## Файлдар

- index.html — сайттың құрылымы
- assets/css/style.css — сайттың безендірілуі
- assets/js/main.js — бет ашылғанда сәлемдесу хабарламасы
- .gitignore — logs және build ішіндегі файлдарды Git-тен елемейді

## Тегтер

- v1.0 — бастапқы HTML және CSS
- v2.0 — JavaScript, Google қарпі және бет бөлімдері қосылған нұсқа
